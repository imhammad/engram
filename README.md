# Engram

Engram is an open-source, privacy-first desktop application that serves as an on-device AI memory graph. Built to act as a "second brain," it continuously processes daily workflows into a secure, searchable local knowledge graph. By leveraging local Small Language Models (SLMs) and on-device vector storage, Engram ensures that all data ingestion, embedding, and querying happen entirely locally—guaranteeing that your personal data never leaves your machine.
